# 通用代码规范

## 代码风格
### 异步编程规则
- 如果涉及到方法可以传递 CancellationToken，则必须传递 CancellationToken。
- 某些方法会有 object 作为参数，其 CancellationToken 则必须显式通过命名参数传递，例如 `await Send.OkAsync(cancellation: ct);`。
- 异步方法都必须以 `Async` 结尾，并且都必须提供 `CancellationToken` 参数，默认值为 `default`。

### 语法糖
- 在可能的情况下，并且可以提升代码可读性和代码量的情况下，可以使用对应的语法糖。
- 所有定义变量的地方，都应该使用 `var` 关键字，除非无法通过上下文推断出变量的类型。

### 时间与区域
- 所有涉及到时间的地方，必须使用 UTC 时间，并且在命名上应该明确指出是 UTC 时间，例如 `createdAtUtc`。
- 取当前时间的时候，使用 `DateTime.UtcNow`，而不是 `DateTime.Now`。

### 注释与 XML 注释
- 公开的类、方法、属性、字段等必须要有 XML 注释，且必须使用中文。
- XML 注释的内容不要复杂，尽量简洁明了，必要时可以使用 `<remarks>` 等标签补充说明。
- 所有注释都应该遵循简单、明了、易懂的原则，避免使用复杂的术语和缩写，请说人话，不要使用奇怪的比喻和隐喻类比。
- 代码内部的逻辑注释只有在必要的时候使用，大部分情况下，代码本身应该足够清晰明了，不需要额外的注释来解释。
- 代码内部的逻辑注释，必须使用中文，简单的还是使用 // ，只有特别复杂的逻辑才使用 /* */ 多行解释。
